# OncoMap V4 — Portfolio Edition

OncoMap is an independent precision-oncology research/knowledge platform.

## V4 additions
- Cancer Explorer
- Therapy Explorer
- Methodology & About page
- Data provenance and limitations
- Research-workflow explanation
- Portfolio-ready project positioning
- ClinicalTrials.gov kept as a live data layer

## Existing capabilities
- 50-record biomarker dataset
- Biomarker search and filters
- Biomarker detail/research map
- Alteration → testing → therapy → evidence workflow
- Compare up to four biomarkers
- ClinicalTrials.gov exploration
- Precision-oncology learning section
- Responsive/PWA-ready static deployment

## Deployment
Upload the contents of this folder to the root of the `main` branch of the OncoMap repository. Keep GitHub Pages configured to `main` / root.

## Disclaimer
Educational/research tool only. Not a diagnostic, treatment-selection or medical-advice tool. Verify primary sources, current regulatory information, guidelines and trial eligibility before clinical use.
